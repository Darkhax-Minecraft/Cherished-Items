<!-- description-start -->
This is the official GitHub repo for the CherishedItems mod. Adds new features and config options related to item despawning. You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cherished-items) or [Modrinth](https://modrinth.com/mod/cherished-items). Please report issues [here](https://github.com/Darkhax-Minecraft/Cherished-Items/issues).
<!-- description-end -->

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.cherisheditems', name: 'cherisheditems-neoforge-26.3', version: '26.3.0.0'
     // Fabric
     implementation group: 'net.darkhax.cherisheditems', name: 'cherisheditems-fabric-26.3', version: '26.3.0.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.cherisheditems', name: 'cherisheditems-common-26.3', version: '26.3.0.0'
}
```
